# 合规审查前端 Demo

这是 `lab-hegui-biz` 的本地前端演示工作台，用于调度 `agents/hegui-agent/hegui_cli.py` 并展示政府采购招标文件审查产物。

## 启动

```bash
python3 demo/server.py
```

打开：

```text
http://127.0.0.1:8765
```

## 第一版范围

- 上传支持的待审文件：`.pdf`、`.docx`、`.txt`、`.md`
- 一键调用 `hegui_cli.py`
- 未开始时只展示上传入口，审查中只展示审查进度，完成后才展示结果
- 按专家审查逻辑展示发布意见：可发布、修改后发布、暂缓发布、需人工复核
- 按审查重点展示基本合规、公平竞争、评分办法、采购需求、合同履约
- 将风险整理为必须修改、建议修改、需人工复核等处理清单
- 审查进度严格展示指引中的 `01-文件画像` 至 `08-运行记录`，并在右侧展示每个阶段的业务关键信息
- 审查完成后展示结果，原始中间产物和技术日志收在“报告与证据”抽屉中
- 渲染 `07-AI审查记录`
- 解析风险台账
- 解析质量门检查表
- 查看全部中间产物原文

## 边界

前端和本地服务只做任务调度与产物展示，不写入政府采购业务审查规则，不修改 LLM Wiki，不修改 `raw/` 原始文件。
